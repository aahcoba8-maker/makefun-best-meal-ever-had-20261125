## The entry

`main.py` (Python 3, stdlib only) writes one sentence to `entry.txt` in the
output directory the grader provides (`MAKEFUN_OUTPUT_DIR` when set, else
`/output`, else the script directory) and prints it to stdout.

## Run

```sh
python3 main.py
```
